# tron2_rl_lab

LimX TRON2A 人形机器人的强化学习训练流水线，基于 Isaac Lab 和 RSL RL。用于在仿真中训练行走策略，然后部署到真机。

## 前提条件

- Isaac Lab 环境
- PyTorch
- RSL RL

## 快速开始

```bash
git clone https://github.com/limxdynamics/tron2_rl_lab.git
cd tron2_rl_lab
pip install -r requirements.txt
```

按照 `scripts/` 目录下的脚本启动训练任务。
